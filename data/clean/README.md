# Clean Data

e-distribución capacity data (see `data/raw/README.md`), filtered per region and split into two subfolders. Generated by `scripts/filter_edistribucion.py` from the 2026-09 raw snapshot.

## aragon/

- `demanda_aragon.csv` — 457 rows, 244 unique substations.
- `generacion_aragon.csv` — 457 rows, 244 unique substations.

## catalunya/

- `demanda_catalunya.csv` — 357 rows, 201 unique substations.
- `generacion_catalunya.csv` — 357 rows, 201 unique substations.

**Column changes from raw:** the source file repeats `Provincia` and `Municipio` twice (once as an INE numeric code, once as a human-readable label). These are renamed to disambiguate: `provincia_codigo`/`municipio_codigo` (code) vs. `provincia`/`municipio` (label). Two columns are added — `lat`, `lon` (WGS84) — converted from `Coordenada UTM X`/`Coordenada UTM Y` via `scripts/geo_utils.py`, assuming the source UTM values are ETRS89 / UTM zone 30N (EPSG:25830, see that script's docstring for why). All other columns are unchanged — see `data/raw/README.md` for field meanings.

**Not yet done:** demand and generation are still two separate files per region (not joined). Re-run `scripts/filter_edistribucion.py` whenever a new raw snapshot is downloaded — it overwrites these CSVs.

## Province boundaries + maps

Each region folder also has:
- `boundary_<region>.geojson` — province outlines for that region, generated by `scripts/filter_boundaries.py` from `data/raw/boundaries/spain_provinces.geojson`.
The interactive maps (province boundary outline + one marker per substation, popup shows name/municipality/summed firm demand capacity) are written to `docs/map_<region>.html` by `scripts/plot_capacity_map.py`, with `docs/index.html` linking to them. `docs/` is published with GitHub Pages.
