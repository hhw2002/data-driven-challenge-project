# GIS data

Geographic layers for Catalunya: administrative boundaries, substation and power-plant locations, and saved IGN service metadata.

- `raw/` — source snapshots. Not in the repo.
- `clean/` — Catalunya layers generated from `raw/`. Kept in the repo.

Substation coordinates used in the grid tables come from the grid sources themselves (e-distribución, CNMC); see `data/grid/README.md`.

## Raw (`raw/`)

Immutable source snapshots. Do not edit these files in place — if a correction is needed, re-download and keep the old version for traceability.

### boundaries/

- `spain_provinces_ign.geojson` — official province boundaries from IGN's INSPIRE Administrative Units WFS (`scripts/fetch_ign_boundaries.py`). Used by `scripts/filter_boundaries.py`.
- `spain_provinces.geojson` — the earlier community-sourced version (codeforgermany/click_that_hood, downloaded 2026-09-17; simplified geometry). Kept for reference, no longer used. Details in `raw/boundaries/README.md`.

### BTN_T_energia.gpkg and ign_btn_energia_gpkg/

IGN's BTN (*Base Topográfica Nacional*) energy theme as a GeoPackage, downloaded manually from the CNIG download centre (centrodedescargas.cnig.es → "BTN Tema - Energía"). `scripts/extract_btn_energy_gpkg.py` cuts out Catalunya's power plants (`btn0713s_cen_elec`) and substations (`btn0719s_tra_elec`) into `ign_btn_energia_gpkg/catalunya_energia.geojson`. This is the authoritative version of the BTN energy layers.

### ign_btn_energia/

The same two BTN layers from an earlier route: IGN's vector tiles, swept at zoom 13 over Catalunya's bounding box (`scripts/fetch_btn_energy_infra.py`). Output `catalunya_energia.geojson`; `tile_cache/` (about 380 MB, 3,370 tiles) only lets a re-run skip tiles already downloaded and can be deleted. Superseded by the GeoPackage above.

### osm_subestaciones/

**Source:** OpenStreetMap, via the Overpass API (`scripts/fetch_osm_substations.py`). Every `power=substation` tagged with a 220 kV or 400 kV voltage inside each region's bounding box.

**Downloaded:** 2026-10-15.

**Files:**
- `catalunya_220_400kv.json` — 105 substations.

Raw Overpass JSON: one element per substation with its tags (`name`, `operator`, `voltage`, …) and a `center` point.

**Why it's here:** REE's capacity files have no coordinates. OSM is used only to locate REE's transmission substations (see `scripts/classify_substations.py`).

**Known limitations:**
- Community-mapped. Names, operators and completeness are not guaranteed; some substations have no name.
- Bounding boxes include parts of neighbouring regions, so the counts above are not per-region totals.
- The public Overpass server often answers 502/504 under load; the script retries with backoff.

### spaignBTN/, spaignLLM/, spaignapi_features_ign.xml

Saved IGN / IDEE service-catalogue metadata (ISO 19139 records with an `index.csv` / `index.html` per folder), downloaded 2026-09-17 while looking for official layers. Reference only; no script reads them.

## Clean (`clean/`)

### Province boundaries + maps

- `boundary_catalunya.geojson` — province outlines for Catalunya, generated by `scripts/filter_boundaries.py` from `raw/boundaries/spain_provinces_ign.geojson`.
The interactive maps (province boundary outline + one marker per substation, popup shows name/municipality/summed firm demand capacity) are written to `docs/map_catalunya.html` by `scripts/plot_capacity_map.py`, with `docs/index.html` linking to them. `docs/` is published with GitHub Pages.
